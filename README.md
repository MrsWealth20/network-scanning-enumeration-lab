# Network Scanning & Enumeration Lab

## Objective

The objective of this lab is to perform network reconnaissance and enumeration against a vulnerable virtual machine using Nmap. The assessment identifies active hosts, open ports, running services, operating system information, and potential attack surfaces within a controlled VirtualBox environment.

---

## Tools Used

- Kali Linux
- Nmap
- Metasploitable 2
- VirtualBox

---

## Skills Demonstrated

- Network reconnaissance
- Host discovery
- TCP port scanning
- Service enumeration
- Operating system detection
- Nmap Scripting Engine (NSE)
- Technical documentation
